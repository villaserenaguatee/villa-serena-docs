# Historias de Usuario Iniciales

> **Contexto del documento:** Este directorio contiene las historias de usuario originales acordadas por el equipo al inicio del proyecto Villa Serena.
> **Referencia de desarrollo:** Representan la base conceptual y funcional con la que **Kimberly** diseñó e implementó la primera versión de las interfaces del frontend.
> **Propósito:** Se preservan como registro del diseño inicial y los requisitos consensuados por el equipo, manteniendo la claridad sobre la evolución del sistema.
